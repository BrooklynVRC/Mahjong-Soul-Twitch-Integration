Mahjong Soul Screen Reader

Watches the game picture (like a screen share) and tells the Twitch and Lovense apps when riichi, wins and results happen. It never touches the game itself.

1. Catch a banner

When a banner appears in game (RIICHI, RON, TSUMO, results…), press Freeze. Slide to the clearest frame, then drag a box tightly around the banner's text.

Live

2. Save it as a template

Tips: pick parts that look the same every time, like the banner's word, not the hand or background. Teach a template for each side of the table where the banner can show up. Colour doesn't matter: matching uses brightness only.

3. Templates

The bar shows how closely the current picture matches each template; the yellow mark is the threshold. A template fires when the bar crosses the mark. Raise the threshold if it fires by mistake; lower it if it misses.

Test the apps without playing

Sends an event to the Twitch/Lovense apps as if the banner had been seen.
