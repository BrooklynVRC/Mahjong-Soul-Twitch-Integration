Screen Reader

Watches the game picture like a screen share and never touches the game. It reads the four scores and works out riichi, wins, deal-ins, draws, your live place and game start/end from how they change. Calibration is shared by the Twitch and Lovense apps.

You probably don't need this page. The app comes with a ready-made calibration for Mahjong Soul (any window size), so detection works out of the box. Only use this page if something isn't being detected. Then press F8 in the game when it happens and teach it here.

Setup

Most people never need this: the built-in calibration covers it. If you do calibrate, press F8 while playing whenever something useful is on screen (a banner, or just the scores). It saves the last 5 seconds to teach from here afterwards.

Live

On a frozen frame where the scores show, drag a tight box around one score, type the number exactly as shown and click Teach. Sideways and upside-down scores are fine: the rotation is detected automatically. Start with your own score.
